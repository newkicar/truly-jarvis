# ADR-0011: 后台续跑与任务完成三通道通知（gui bgnotify）

**状态:** 已接受（2026-11-01）

## 背景

两条 GUI 需求：
1. **后台续跑**：yolo 模式下，切项目/切会话/新建对话不应取消正在后台运行的任务；
2. **任务完成提醒**：后台任务（定时任务 / yolo 后台回合）完成后以醒目方式通知用户（会话树标记、提示音/语音、邮件三通道全上）。

## 先例调研（对照 GitHub 成熟框架）

- **codex**：任务 = 独立进程/独立 session，天然互不干扰、完成提醒走进程退出 + UI 层聚合。deepagents（本库）是同进程 LangGraph 图，**官方无跨项目/跨会话 runtime 保活设施**（查 langchain-deepagents 文档：create_deep_agent/checkpointer/subagent 均为同进程原语）。⇒ 自研 `RuntimeRegistry` busy-keepalive 是合理取舍，非闭门造车：语义对齐 codex 的「任务生命周期独立于 UI 会话」。
- 通知三通道均为 Windows 平台标准手段（Win32 MessageBeep / SAPI System.Speech / Outlook COM），无外部依赖、纯 stdlib。

## 决策

### Item 1：RuntimeRegistry busy-keepalive（commit `4fb6d60`）
1. 切项目/新建会话：复用或新建 entry 置活动；**busy（执行中）runtime 后台续跑，只回收 idle runtime**；`is_running`/`proceed_if_running` 降为遗留 no-op。
2. 后台项目完成后其 `task_done` 事件照常进入通知路径（root 归一用 `normalize_root_key`），与前台会话一致。

### Item 2：任务完成三通道通知（commit `ddbfdd7`）
1. **事件**：`src/gui/events.py` 的 `UiBridge.task_done = Signal(object)`（queued，worker/scheduler 线程 → 主线程安全），载荷 = `TaskDoneEvent`（kind=chat/scheduled、root、thread_id、ok、detail、title 缺省按 kind+ok 生成）。
2. **策略**：`src/gui/notify_policy.py`——`NotificationPolicy.from_config`（`jarvis.json` `notifications` 段，缺省**仅提示音开**）；`TaskNotifier.fire` 逐通道调用 hooks，**通道异常绝不外抛**，返回每通道状态串（`ok` / `disabled` / `skipped:no-recipient` / `skipped-non-windows` / `error:...`）；非 str 返回归一为 `"ok"`。
3. **通道**：`src/gui/notify_channels.py`（纯 stdlib）：
   - `sound`：ctypes `MessageBeep(0x40)`；
   - `voice`：PowerShell `System.Speech` SAPI 播报（`-EncodedCommand` UTF-16LE base64，中文安全；值经 `_ps_literal` 单引号翻倍注入）；
   - `email`：Outlook COM `CreateItem(0) + .Send()` 非交互直发（不弹窗）；Outlook 未装 → `error:` 状态串，不崩。
   - 非 Windows 一律 `skipped-non-windows`。
4. **接线**：`gui_main._task_done_hook` → `bridge.task_done.emit`；`MainWindow` 消费 → 项目树 `●`（成功）/ `✗`（失败）醒目标记（会话行 `● ` 前缀、项目行尾部 ` ●`），**消费语义**：打开该会话或切到该项目即清除；该会话新回合开始清 mark；**取消的回合不提醒**（用户有意识操作）；`_on_notify` 压平多行（状态栏单行纪律）。
5. **定时任务**：`scheduler.make_scheduler/reload_schedules/register_jobs/_run_task` 增加 `on_done` 透传（成功 `(task, True, *.md)`、失败 `(task, False, *.error.md)` 且原异常照抛）；钩子异常被吞（调度线程路径，不影响任务本身）；缺省 `None` = CLI/TUI 零开销。

## 配置示例

```json
"notifications": { "sound": true, "voice": false, "email": false, "email_cfg": { "to": "me@example.com" } }
```
