# v0.1.1（2026-11-17）

小版本：side 侧边会话 + 本轮 GUI/TUI 修复包。

## 新增：/side 侧边会话（临时问一嘴，关了就没了）
- **内核**：thread 级 side 状态（open / close / dispatch），side 会话拦截 `task` 工具不 fan-out 子代理；
- **TUI**：Header 显示 `[SIDE]` 徽章，`/side` / `/side close` 命令；
- **GUI**：「回主线」pill + 侧栏菜单入口，对话流 ◇ 前缀区分 side 消息；
- **隔离**：side open/fork 显式分配新 thread id，主线历史零污染；
- **只读**：side 内写工具（write/edit/delete）全拦，`execute` 一并拦（只读只搜）；
- **不落盘**：`/side close` = 删除该 thread 的 checkpoint 与历史——side 的意义就是临时，关了就没了，GUI/TUI 对话区同步清屏。

## 修复
- **400 "System message must be at the beginning"**：SystemHeadMiddleware v2 在每次调用时合并 System 头，
  修复 side 多轮会话 checkpoint 重放导致的网关 400（12a28b6）；
- **GUI 从列表移除项目即解除占用**（3404b9e）：取消在跑回合 / 清空消息队列 / 停调度器 / 关闭 runtime，
  checkpointer 连接释放后项目文件夹可正常删除（原先右击「从列表移除（不删文件）」后文件夹仍被占用）；
- **TUI Esc 取消即时化**（4e131fc）：双 Esc 取消不再等回合收尾，`kill_active` 硬杀 execute 进程树，与 GUI 立即取消对齐；
- **GUI 状态栏**（bc0dcbf）：StatusView 替代 QLabel，命令输出可复制 + 自动换行（不再撑宽窗体）。
