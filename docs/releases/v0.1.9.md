# v0.1.9（2026-11-26）

侧边会话双槽输入 + 目标（goals）持久续跑 + 替我审批（/approve-for-me）：本版本三块主线，覆盖 TUI/GUI/CLI 三前端。便携包重建。

## 主线一：侧边会话（side-session，双槽输入）
- TUI 双 pane 布局（50/50 条件渲染）：`#side_pane` 骨架 + CSS 镜像 + `_refresh_split_layout` 四处 hook（命令结果焦点路由 / 会话切换孤儿联动 / 新建会话收起 / 启动同步）；
- `/side` 任何时候可开：历史无 terminal 检查点时 fork head 快照并剥离悬挂 tool_calls；侧槽拒收 + `/side` `/side close` 主线程直调 + pill 跟随右槽；
- 路由收敛三连修：门判定改读当轮 thread-local tid（双真源收敛）→ 侧输入框提交路由到当轮侧线程 → 切会话右槽跟随 + close 路径折叠后置；
- GUI：QSplitter 双槽布局 + 双线程并发流式预检 + 目标 82 绿 / 全量 1599 绿回归留痕；
- 重构：pane 寻址收敛为纯 helper `resolve_panes`（PaneLayout frozen dataclass 四态矩阵），显示零变化。

## 主线二：目标续跑（goals，对标 codex goal 机制）
- 内核：`/goal` 持久目标——`goals.json` 存储（int 墓碑保 goal_id 序列）+ 四态状态机 + `should_continue` 判定 + 双 prompt + `goals.max_turns` 配置；`run_agent_turn` 返回 `TurnOutcome` 结构化单轮结果；
- 模型侧工具 ×3：`create_goal` / `complete_goal` / `get_goal`（仅主代理注入，MCP 同款位，子代理不含）；
- 三前端接线：TUI 自动续跑（turn finally 入 TurnGate FIFO + 预算后置终态 + `[GOAL]` sub_title）；GUI+CLI 自动续跑（`_cli_goal_step` while 续跑 / mark 独立 kind 门 / 会话切换 + 回合结束目标状态行 / 断链留痕 + create/resume 重启手柄 + 目标徽标与常驻状态行）；
- 收口：三前端目标续跑收口统一为 `goals.after_turn` 单入口；after_turn 补 11 条单测；ADR-0013 落档。

## 主线三：替我审批（/approve-for-me）
- ADR-0014：GUI 高级菜单「替我审批」+ `/proxy` 等价别名 → 本版本正名为 **`/approve-for-me`**（`/proxy` 保留等价别名），六层同步（commands dispatch 双名路由 + slash 补全 + TUI 三族通知泛化 + GUI 菜单/徽标/状态栏 + 测试 + 文档）；复用 `permissions.proxy_*` 内核零改动；
- 同批：GUI 压缩基线显示（🗜 / 合并重建）、P3 `deleteLater` 闪退修复、`faulthandler` 留栈、压缩续跑提示词。
