# v0.1.12（2026-11-28）

v0.1.12 亮点：/proxy 语义裁决层（#18–#22）——LLM 替我审批 · 指纹幂等缓存 · fail-closed 审计 · 线程级断路器 · context_aware 有界只读探查

## 亮点
- **proxy 审查层纯 expand 装配（#18）**：config PROXY_REVIEW_DEFAULTS（breaker deny_streak 3 / deny_in_window 10 / window 50，timeout_s 30，retries 3）+ permissions 共享 state 键 + agent inject_proxy_review_deps；proxy 段缺省全默认深拷贝、model 空回落主模型
- **proxy.review 裁决层 allow-only（#19）**：LLM 替我审批——low/medium→allow，high→allow 仅当 authorization≥medium 且 narrow-scope，critical 一律 ask；模型异常/坏 JSON/枚举越界 fail-closed 回落人工审批；sha1 指纹 LRU 缓存（1000）命中零模型调用；jsonl 审计落 ~/.jarvis/logs/proxy-review.jsonl（写失败静默）
- **TUI/CLI 呈现与配置 UX（#20）**：allow 裁决呈现 ⚡ proxy-review 放行标记（TUI 折叠/展开条目 + CLI 行）；回落 ask 时可展示裁决 note；JARVIS_JSON_TEMPLATE 增 proxy.review 默认块（enabled=False）
- **一次性覆盖 + 线程级断路器（#21）**：人工放行模型 deny 记覆盖预算（上限 10，弹窗改标「一次性覆盖」）；streak≥3 或 50 次窗口内 deny≥10 → 熔断 sticky 回落人工审批，allow/ask 清 streak
- **context_aware 有界只读探查（#22）**：缺省关，jarvis.json 可开；一阶段「定不了」时二阶段拉最近 3 条更早用户消息 + git diff --stat（总量 2000 字符 + 子进程 10s 超时，失败静默）；只松动不收紧，stage-2 拒绝/解析失败/critical 维持 ask
