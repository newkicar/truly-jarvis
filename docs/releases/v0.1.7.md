# v0.1.7（2026-11-23）

上下文压缩 keep-first（默认不钉头）+ 项目状态目录 .jarvis/ 统一 + 内部 LLM 128K 上下文超限 400 修复。

## 上下文压缩（keep-first）
- **新模块 src/context_compaction.py**：KeepFirstCompactionMiddleware（deepagents 原生 SummarizationMiddleware 子类）+ build_compaction_middleware 工厂。触发、切点、外置备份、事件模型全部继承上游原生实现，只覆写 summary 生成钩子（sync/async 两条 wrap_model_call 路径）；
- **默认不钉头**（keep_first=0）：被裁区间整体交 LLM 总结，行为与原生 deepagents 完全等价；保留最近 6 条（未配 auto_compaction）或 20 条（auto_compaction>0）；
- **jarvis.json 新增 keep_first_messages**（默认 0）：>0 时开头 N 条消息逐字 XML 钉进 summary（## Pinned conversation head 块，不经 LLM），中间段仍走 LLM 总结；链式压缩时更早的原文随 summary 逐字传播，整个压缩链不丢；非整数 warning 回落 0、负数兜底 0；
- **修复 auto_compaction 分支 trim 漂移**：此前 auto_compaction>0 且未显式传 trim 时透传 None（整段历史进 LLM prompt）；现保持类默认 4000；
- 被裁历史备份路径不变：conversation_history/{session_id}.md（dev 在项目根 .jarvis/，release 在 ~/.jarvis/）。

## 项目状态目录（.jarvis/）
- 项目级运行态统一收纳 .jarvis/：checkpoints/、sessions.json、memory/、conversation_history/；遗留根路径（checkpoints/ 等散在项目根）启动时幂等迁移，异构目标不覆盖；
- 大工具结果外置 .jarvis/large_tool_results/；
- Config.context_limit 落到模型 profile 的 max_input_tokens；auto_compaction 按 token 触发——修复「131073 input tokens 超 131072 上限 400」事故（内部 LLM 128K 上下文 + 旧默认压缩阈值不匹配）；
- /init 模板、GUI（doctor / session_registry / workspace）、memory_dir、project_paths 联动。
