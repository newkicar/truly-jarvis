# v0.1.3（2026-11-18）

小版本：`/use` skill 补全任意位置锚定（TUI+GUI 共享内核，tui-ux24）+ GUI skill 单字符无匹配弹层显示（gui-ux25，顺手 off-by-one 修复）+ 首启向导生成安装目录 .env（gui-ux26，便携版缺 .env 报错修复）+ 源码版/便携版拉齐。

## 新功能：/use skill 补全任意位置锚定（tui-ux24，TUI+GUI 共享内核）
- **根因**：`tui_completion.use_query` 只认 `text.startswith("/use ")`（文本开头锚定）——句中/续行「空格 + /use」触发不了 skill 后缀候选（@ 与 / 在 0.1.2 已泛化任意位置，/use 是唯一遗留的开头锚定触发器）；
- **修复**（1014280）：`use_query` 泛化任意位置锚定，对齐 `slash_query`/`at_query`——`rfind("/use ")`，其前一字符为行首或空白才触发；`query` = 「/use 」后至光标文本，遇第二个空格关闭（说明段输入关 overlay）；返回 `(idx+5, query)`，`idx+5` = 真实 query 起点；
- **边界不变量**：query 含空格时 `slash_query`（遇首空格截断）让位 → use_query 接住；裸 `/use`/`/uses`（无尾随空格）保持 slash 补全语义（命令清单含 /use 自身）；`apply_suggestion`/`apply_suggestion_on_line` 全按 `state.at_index` 通用拼接，零硬编码，句中 Tab 接受保住前缀、多行只改光标行；
- **双端一处修生效**：GUI `resolve_for_input` 先 `line_projection` 取光标行再走同一 `resolve_overlay_state` 内核，TUI+GUI 同批修复（续行/句中 `/use ` 触发 + Tab 接受只改光标行）。

## 修复：GUI skill 单字符无匹配弹层显示（gui-ux25，顺手 off-by-one）
- **根因**：`gui/completion.has_query_no_match` 对所有 kind 统一 `at_index + 1` 跳过 query 首字符——但 skill kind 的 `at_index` 已是 query 起点（「/use 」之后），slash/path kind 的 `at_index` 才是「/」「@」位置（`+1` 正确）→ skill 单字符查询被误判为空 query → 弹层整体静默消失（无「No matching items」提示行）；
- **修复**（1014280）：按 kind 分支 `start = at_index（skill）/ at_index + 1（slash/path）`。

## 修复：首启向导生成安装目录 .env（gui-ux26，便携版缺 .env 报错修复）
- **根因**：jarvis 运行依赖 `.env`，便携版无 `.env` 也无 `.env.example` 进包 → 裸 `load_config()` 调用点（`/skills`、`/doctor`、`/rollback-vault`、`/reload-schedules`、`/dream`、scheduler）缺必需 4 键直接 KeyError；
- **修复**（用户推荐方案 2：首启时生成，用户不操心）：首启向导保存 LLM 配置时，`LlmWizard.save()` best-effort 调 `llm_config.sync_install_env(cfg)` → 自动在**安装目录**（frozen=exe 目录；源码版=仓库根）生成/更新 `.env`：管理键 `BASE_URL`/`API_KEY`/`MODEL_ID` 原地重写（既有行无论 `=`/`:` 分隔都认），用户其他行（注释、SOK/TAVILY 等）原样保留，缺 `TAVILY_KEY` 尾插空值行，原子写、失败仅 warning 不崩保存流；
- **兜底**：`load_config` 查找序本有「项目 .env → 安装目录 .env」，生成后即覆盖全部裸调用点；缺键 KeyError 文案同步加指引（「请将 .env 放到项目根目录或安装目录；GUI 版完成首启向导会自动生成」）。
