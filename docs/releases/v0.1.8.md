# v0.1.8（2026-11-24）

CI 兼容修复：①测试 fake 模型适配 langchain≥1.5 的 with_retry 签名漂移；②TUI Esc 取消类测试时序加固（假流太短在慢 CI 上提前跑完，Esc 误入空闲撤回分支）。无运行时行为变化（产品代码零改动），便携包重建。

## 背景
- CI 解析 `langchain>=1.3.14,<2` 到 1.5.2；新版 `LCSummarizationMiddleware.__init__` 改调 `model.with_retry(retry_if_exception_type=...)`，旧测试 fake 的无参 `with_retry` 触发 TypeError（tests/test_context_compaction.py 11 条红）；
- 本地 venv langchain 1.3.18 无参调用，故本地绿、CI 红；
- `tests/test_tui.py::test_escape_cancels_streaming` 在 CI（Python 3.12，事件循环偏慢）下红：假流总时长 0.2×2s 被 `asyncio.sleep(0.1)` 拉伸后提前跑完 → `worker.is_finished` → 两次 Esc 全落入空闲双-Esc 撤回分支（`_trigger_implicit_undo` → `commands.undo` 调 `agent.get_state`，FakeAgent 无此属性 → transcript 被清空）→「已取消」断言失败。

## 变更
- `tests/test_context_compaction.py`：`_FakeModel.with_retry(self)` → `def with_retry(self, *args, **kwargs): return self`，兼容 langchain 1.3.x / 1.5.x 双版本；
- `tests/test_tui.py`：Esc 取消类 3 条测试时序加固——新增 `_wait_streaming_active` 前置等待（轮询 `app._turn_workers[app.thread_id]` 存在且 `not is_finished` 才放行），假流 sleep 0.2→0.6s（总 1.2s）；`banner_replaces_spinner` 尾部收尾等待 0.9→1.4s；**产品代码零改动**（tui-ux7 取消/撤回语义与既有测试不变）；
- 无源码/运行时行为变化；便携包以同一源码重建。

## 测试
- ci-venv（Python 3.14.7，langchain 1.5.x，对齐 CI 版本线）：tests/test_context_compaction.py 11 passed；
- 同上：tests/test_tui.py Esc 取消类目标测试（escape_cancels / banner_replaces / kill_active）单次 4 passed，连跑 30 次全绿。
- 全量非 GUI 回归（对齐 CI 命令）：1306 passed / 1 skipped / 0 failed（ci-venv，Python 3.14.7 + langchain 1.5.2，命令对齐 CI 非 GUI 子集；GUI 子集由 CI 兜底）。
