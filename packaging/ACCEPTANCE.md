# JARVIS GUI 干净机验收清单（工单 14）

人工验收为主；执行机 = 干净 Win10/11 或全新 VM（杀软在线、无开发者环境）。
执行前：`packaging\build_gui.ps1` → `sign_release.ps1` → ISCC 出 `Jarvis-<ver>-setup.exe`。

## 1. 安装 → 首启 → 配 LLM → 对话

- [ ] 安装 `setup.exe`（UAC 通过；安装目录 `C:\Program Files\Jarvis`）
- [ ] 桌面/开始菜单快捷方式可用；首启**秒级出现向导**（记录启动时间补 runtime-info.txt）
- [ ] 向导 5 步：公司网关（或第三方端点）→ 探测成功 → 保存
- [ ] 对话框发「列一下当前目录」：真实流式回答上屏（Markdown 渲染、思考块可见）
- [ ] 模型/耗时标注、状态行、spinner 正常
- **判定**：全程无 Python/Qt 报错弹窗；安装目录无新增写入（资源监视器或目录时间戳对比）

## 2. 各能力走一遍（截图存档）

- [ ] **审批卡**：让 agent 跑 `execute`（如 `Get-Date`）→ 卡片出现（命令 diff）→
      放行 → 结果工具行；再「永久放行」（前缀框可编辑）；拒绝路径 → 换方案引导
- [ ] **图片附件**：粘贴一张截图进输入框 → 缩略图条出现 → 点击放大 → 移除；
      发送多模态消息（网关支持时）
- [ ] **工具详情**：工具行「＋详情」展开参数/结果；回放不丢工具记录
- [ ] **AI 命名**：新会话首轮结束后侧栏自动出现短名；双击可改
- [ ] **排队/回合门**：执行中连发两条消息 → 「排队中 N」提示 → 收尾后 FIFO 投递
- [ ] **会话切换**：≥3 会话来回切，各会话记录完整不串
- [ ] **撤销/时间旅行**：`/undo`（双键或菜单）→ 消息层回退；时间旅行菜单
      快照/列表/回放各点一遍（无快照时友好提示）
- [ ] **高级**：Plan 模式切换（写工具被拦）；YOLO 开关（徽章 + 免审批）
- [ ] **命令/补全**：`@` 路径 / `/` 命令 / `/use` skill 弹层 Tab 接受；筛选命令对话框
- [ ] **主题**：明暗切换 + 重启恢复（%APPDATA%\Jarvis\gui.json）
- [ ] **自检页**：「命令 → 自检（Doctor）」各区块状态与本机一致
      （Ollama 未起 = warn 且给指引；chromadb 未装 = warn 且给 pip 指引）

## 3. 卸载重装（用户数据分离实证）

- [ ] 记：LLM 端点配置、会话短名（≥1 条 AI 命名）、`~/.jarvis/memory` 内容

- **判定**：安装/卸载全程不碰 Program Files 之外的系统位置（除用户数据勾选）
