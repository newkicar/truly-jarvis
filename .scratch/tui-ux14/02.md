# 工单 02：YOLO 徽章（输入框最右 + 切回联动）

## 实现
- compose（L1109-1134）：#editor_frame 内 #input 之后加 Static("", id="yolo_badge")。
- CSS（仿 #todo_panel L910-923 范式）：
  #yolo_badge { display: none; width: auto; height: 1; border: round 20% $error 80%; padding: 0 1; }
  #yolo_badge.-active { display: block; }
  （勿写 can-focus 伪类——Textual 8.2.8 CSS 解析炸；容器用 VerticalScroll(can_focus=False) 构造参数惯例不适用，badge 是 Static 无焦点问题。）
- _refresh_yolo_badge()：try/except NoMatches 守卫；active = yolo_active(self.permission_state, self.thread_id)；
  active → badge.update("[b]⚠ YOLO[/b]") + badge.classes.add("-active")？（Textual 用 set_class / classes.discard）；
  非 active → 清空文本 + 去 active class。
- 调用点：_update_sub_title() L1068 末尾调用（覆盖 on_mount / _apply_command_result / _adopt_thread / _switch_session 全链路）。

## 测试（test_tui.py）
- T1 yolo_active=true 时徽章 visible 且含 "YOLO"；false 时 hidden。
- T2 切到非 YOLO 会话 → 徽章隐藏；切回 YOLO 会话 → 徽章重新显示（模拟 _switch_session 两次）。
