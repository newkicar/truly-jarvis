# 工单 03：YOLO 后台任务持久（切会话不中断）

## 实现
- tui.py __init__：self._worker: Worker | None → self._workers: dict[str, Worker] = {}；
  新增 self._bg_turns: set[str] = set()。
- 6 spawn 点（L1349 /replay、L1360 /undo、L1373 /use、L1379 普通命令、L1394 主流、L1475 双 Esc）：
  方法开头 tid = self.thread_id，run_worker 结果存 self._workers[tid]（先 cancel+discard 该 tid 已有 worker，防叠）。
- _cancel_stream_worker（L1477-1480）与 action_cancel（L1875-1895）：self._workers.get(self.thread_id) 语义不变
  （cancel 后 pop）。
- _leave_current_thread(old)（L1518-1528）：if yolo_active(self.permission_state, old)：
  跳过 L1524 cancel 与 L1528 finalize_turn，L1525-1527 HITL choreography 保留，old 入 _bg_turns；否则维持现状。
- _release_turn_gate(tid)（L1216-1233）：tid in self._bg_turns → 静默保留该 thread 队列（不作废、不 notify）+ _bg_turns.discard(tid)；
  否则维持现有「作废旧 thread 队列 + notify」语义（非 YOLO 场景不变）。
- _switch_session（L1540-1556）：adopt 后 if 该 thread 门已释放且 registry.has(tid)：重投队首（registry.pop_first → 走正常提交通道）。
  （registry 在 04 落地；03 阶段先对 self._queued_messages 实现，04 切换单一事实源后自动覆盖。）
- tui_turn.py：__init__ 捕获 self.thread_id = app.thread_id；L126/L149/L174/L180 live self.app.thread_id → self.thread_id；
  L209 self.app._hide_spinner() → self.app._hide_spinner_if_idle()（新：workers dict 有未 finished worker 不隐藏）。

## 测试（test_tui.py / test_tui_turn_gate.py）
- T1 非 YOLO：切换会话 → 旧 thread worker 被 cancel + finalize（现状行为回归）。
- T2 YOLO：_leave_current_thread 后旧 thread worker 仍在 _workers 且未被 cancel；_bg_turns 含旧 thread。
- T3 YOLO 后台 turn 结束（_release_turn_gate）→ 旧 thread 队列消息保留（不 notify 作废）。
- T4 切回 YOLO thread → 队列重投队首。
- T5 非 YOLO 后台 turn 结束 → 现有作废 + notify 行为回归。
