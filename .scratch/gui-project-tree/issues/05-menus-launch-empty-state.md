# 05 — 打开/新建 菜单 + 启动选最近 + 空状态 + 标题/状态显示项目名

**What to build:** 把票 02/03 的内核接到主窗口 UI 上：菜单栏新增「打开项目」「新建项目」两个下拉并保留既有菜单；应用启动时打开最近项目；空注册表给引导式空状态；标题栏/状态行显示活动项目名。这条是「把多项目工作区跑起来」的最后一块。

**Blocked by:** 02, 03, 04（需要内核、切换、树都已就位）

**Status:** ready-for-agent

## 菜单栏
- 顺序定为：`打开项目 | 新建项目 | 命令 | 主题 | 时间旅行 | MCP 工具 | 定时任务 | 高级`（既有菜单全保留，不挪不走）。
- **打开项目**（下拉）：`最近项目`（列表 = 01 排序结果，点一项 = 委托 03 切过去）＋ 分隔 ＋「打开文件夹…」（`getExistingDirectory` → 委托 02 打开判定；缺配置时按 02 的「需初始化」弹一次确认后骨架）。
- **新建项目**（下拉）：「新建项目…」（名字 + 选父目录 对话框 → 委托 02 新建 → 03 切过去；以后可加「模板」）。

## 启动 / 空状态
- 启动 = 打开 01 的「最近且仍存在」项目（03 切过去 + 打开其 `last_active_thread`）。
- 空注册表（或最近的目录都不在了）= 侧栏空状态：一句「还没有项目」+ 「打开项目」「新建项目」两个主按钮；主区给友好占位。**不**偷造默认 scratch 项目。

## 标题 / 状态
- 标题栏 = `JARVIS — <活动项目显示名>`（模型名从标题降级到状态区/主题区；空状态 = `JARVIS`）。
- 状态行 = `<活动项目> · 会话 <短名或 id>`（有回合在跑接 `…`）。

## 验收
- [ ] 菜单栏 8 项顺序正确、既有菜单仍可用；「打开项目」下拉列出最近项目且点开能切；「打开文件夹…」「新建项目…」分别走 02 的打开/新建 + 03 切换。
- [ ] 启动：注册表非空 → 打开最近项目并切到其上次会话；空 → 侧栏出空状态两按钮、主区占位、无幽灵项目。
- [ ] 最近项目目录被删 → 启动跳过它取下一个；全没了 → 空状态。
- [ ] 标题串随活动项目变（有项目 = `JARVIS — <名>`；空 = `JARVIS`）；状态串含「项目 · 会话」。
- [ ] 全流程 offscreen（monkeypatch 03 切换器 / 02 判定，不碰真模型、不弹真文件对话框——对话框用 fake 注入）；断言落在菜单项集合、标题/状态文案、活动项目归属。

- 不做「项目设置」配知识库/记忆（Out of Scope）。
- 不做项目列表拖拽排序（Out of Scope）。
