# 04 — 侧栏项目树（项目 → 会话；点项目名=切换，右键菜单）

**What to build:** 把现在侧栏里那个平铺的会话列表，换成「项目 → 会话」两层树：顶层是「项目」分组，每个项目是一个节点（`+/−` 展开/收起其会话），项目下挂它的会话（活动/置顶/运行/归档标记沿用）。**点项目名 = 切进该项目**（委托票 03）；点会话叶子 = 切到该项目 + 该会话。项目与叶子的右键菜单各就各位。

**Blocked by:** 01, 03（要能列出注册表项目、能切 runtime、能只读取非活动项目会话名）

**Status:** ready-for-agent

## 结构
```
（标题） JARVIS
项目            ← 静态分组标题（不可点）
  ▸ 项目A −       ← 项目节点：点名字=切进；+/−=展开/收起
      会话1 ▸     ← 活动会话带 ▸
      会话2
  ▸ 项目B +
──────────────
＋ 新会话          ← 作用在活动项目（沿用底部）
[Act] / ⚡ / ★     ← 模式/运行/置顶 徽标留底部（沿用）
```

## 交互
- 项目行：点**名字** = 委托票 03 `switch_to`（有进行中回合 → 触发那个确认）；`+/−` 仅展开/收起。
- 非活动项目的叶子名 = 票 03 `list_sessions_readonly`（不加载其 runtime）；活动项目的叶子 = live 列表。
- 叶子：点 = 切到该项目 + 该会话；活动 ▸ / 置顶 ★ / 归档 📁 / 运行 ⚡ 标记沿用。
- **项目右键**：重命名 / 置顶 / 资源管理器打开 / 移除（只删登记，委托 01）。
- **会话叶子右键**：沿用现有 分享/下载/重命名/置顶/克隆/归档/删除 一整套。
- 展开/收起状态记在 UI 偏好，默认展开活动项目。

## 验收
- [ ] offscreen 下：注册表 3 项目 + 各项目 sessions.json 若干 → 树渲染出「项目→会话」且非活动项目叶子名正确（来自只读）。
- [ ] 点项目名 → 触发 03 的切换（可用 fake 断言目标项目成了 active、旧 runtime 关闭）；`+/−` 只改展开态、不切项目。
- [ ] 点叶子 → 切到该项目 + 该会话（活动标记随之移动）。
- [ ] 项目右键「移除」后该项从树消失但**项目文件仍在**；「资源管理器打开」「置顶」「重命名」生效且写回 01。
- [ ] 会话叶子右键菜单七项齐全（沿用现有 handler，不回归）。
- [ ] 用 pilot/qtbot 驱动 + monkeypatch 掉 03 的切换器（不碰真模型）；断言落在树的节点集合/文案，不落私有属性名。
