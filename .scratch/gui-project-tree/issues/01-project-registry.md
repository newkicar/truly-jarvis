# 01 — 项目注册表 `project_registry`（全局 projects.json）

**What to build:** 一份全局项目注册表，作为多项目工作区的「导航/记账」层：登记已知项目、按最近/置顶排序、记住每个项目的显示名与上次活动会话、并决定「启动时开哪个」。它本身纯逻辑、可离 GUI 单测，只读/写用户主目录下的注册表文件，**永不**碰项目文件夹里的数据。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

## 范围
- 注册表文件落在用户主目录（`~/.jarvis`）下，可被 `JARVIS_HOME` 覆盖。
- 条目字段：`path`（已解析绝对路径）、`name`（显示名，默认=文件夹名，可改）、`pinned`、`last_opened`（epoch）、`last_active_thread`。
- 顶层额外一个 `active`（当前活动项目路径）。

## 验收
- [ ] 加入项目按**已解析绝对路径去重**：重开同一目录不产生第二条。
- [ ] 列表排序 = **置顶优先，其次 `last_opened` 降序**；置顶只改顺序、不加分外语义。
- [ ] 可 改名 / 置顶(开/关) / 记 `last_active_thread`；**移除只删注册表项**，绝不触碰项目文件夹。
- [ ] 启动选取：取最近且**路径仍存在**的项目；跳过错过的；全部不存在 → 返回空（上层落空状态）。
- [ ] 文件缺失/损坏 → 视为空注册表，不崩。
- [ ] 纯函数 + 单测（沿用受管自建目录，禁用 tmp_path）覆盖上述全部；文件内容按「外部行为」断言（读回即判）。

## 非目标
- 不做打开/新建/切项目的动作本身（票 02/03）。
- 不做侧栏渲染（票 04）。
- 不做跨项目全局搜索、多用户同步、拖拽排序。
