# 03 — 分屏交互语义（焦点 / Esc 三级 / slash / 补全 / 草稿 per 槽）

**What to build:** 双槽布局下所有交互以「焦点槽」为准：① 每槽 InputBar 独立输入草稿
（草稿不跨槽跟走）、独立 tab/esc/cancel hooks；② CompletionPopup 每槽一个
（L272-287 绑定逻辑复制、120ms 刷新不变），仅焦点槽的 popup 活跃；③ Esc 三级状态机
（L289-296：run-cancel → 双 Esc undo → 空闲）升为槽级，每槽独立 primed 时间戳、
作用于该槽 tid；④ `_submit` / `_route_slash`（L1231-1331）/ `_cancel_active` 一律路由
焦点槽 tid（替代全局 active_tid 语义）；⑤ 切换焦点不中断任一侧在跑的流；
⑥ close_side（「← 回主线」/ 树右键删）→ 焦点回左槽、右槽折叠。

**Blocked by:** 02

**Status:** ready-for-agent

- [x] close_side 后焦点回左槽且左槽输入框获得焦点
