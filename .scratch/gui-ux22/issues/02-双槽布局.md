# 02 — QSplitter 双槽布局（左主线 / 右侧边）

**What to build:** 中央区改水平 QSplitter：左槽 = 现有单列四件套（StatusView/QueueStrip/
ImageStrip/InputBar，`main_window.py` L242-261），右槽 = 同形四件套（各独立实例、
绑自己的 pane 组）。右槽默认折叠（不可见/0 宽）；开侧边会话时（slash 或树右键
「开侧边会话」）展开 50% 宽，ChatPane 从 `panes` dict re-parent 到右槽（per-thread
常驻 / sticky-bottom / 150ms flush_dirty 全不变）；关侧边后右槽折叠。现有
`side_pill` 按钮（L236-241「← 回主线」）挪到右槽头部，点击 = close_side。
无侧边会话时布局与现状完全一致（单槽占满，回归）。
