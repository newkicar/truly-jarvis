# 01 — 双线程并发流式预检（SqliteSaver 并发 + 事件归属）

**What to build:** 分屏「双槽同时在跑」之前的并发地基预检：同一 app 实例里，主线 tid 与
side tid（`side-*`）各挂一个正在跑的 graph（两个流式 worker 并发写同一 SqliteSaver）：
① 无锁竞争炸穿 / 无 finalize_turn 交错（tui-ux7 已知事故根因「无守护 run_worker →
同 thread 双 graph 并发」的 GUI 侧对应防护需确认）；② UiBridge 事件（status/queue/
HITL 卡片/队列 badge）按 tid 前缀严格路由、不串归属；③ 与 GUI ADR-0011 后台续跑语义
兼容（后台 tid 的事件在双槽呈现下不丢）。交付物 = 预检测试套件（gui_fakes +
monkeypatch 双流源）；若发现并发防护缺口，只补 GUI 层 per-tid 防护（worker 隔离 /
turn gate），内核与 streaming 仍零改动。

**Blocked by:** 无

**Status:** ready-for-agent

- [x] 双 tid 并发流 offscreen 测试：两 graph 同时在跑、无异常无死锁、finalize_turn 各自在所属线程收口
- [x] HITL 卡片归属：两侧同时挂起审批 → 各槽显自己的卡，决策互不污染对方 resume（契约 dict 同构断言）
- [x] queue strip / 状态行按 tid 归属不串；sched-* 后台线程事件不出现在双槽（回归）
- [x] 若发现防护缺口：GUI 层 per-tid 防护补齐并记录改动点，内核 / streaming 保持零改动（预检未发现防护缺口，SqliteSaver 并发无炸）
