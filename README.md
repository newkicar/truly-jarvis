> AI时代，agent最重要的任务并不是自动完成工作，而是扩展人类的心智
>> 机器出现：人类的力量变强了，需要更多的计算
>> 计算机时代：人类的计算能力变强了，需要更多的共享
>> 互联网时代：人类的信息共享能力变强了，需要更多的注意力
>> AI时代：AI的真正用途是：可以帮人类过滤无用的信息，总结有用的信息，以使得人类的注意力不再稀缺——>本项目的最重要目标
>> 自动化工作：是每个时代都会出现的副产品：机器时代自动化的机器、计算机时代自动化的软件、互联网时代自动化的系统、AI时代自动化的创作

主要编程语言：python
主agent库：deepagents
主要功能：
1. 心智能力：核心能力，增强用户的心智，通过搜索互联网+本地知识库，过滤掉无用信息，保留并总结有用信息，以帮助用户快速掌握最新资讯、技术动态、行业知识
   - 指定检索
   - 定时检索
2. 自动化能力：借助skill、mcp、tools等
   - deepagents有原生的工具，如：ls、write_todo、read_file等，原生工具要有效使用，不要重复造轮子
   - 须要保留安装skill、mcp的接口，以便于后期能力扩展
3. 原生能力：
   - localshellbackend
   - 长短期记忆（先去搜索当前最优秀方案）
   - 模拟opencode的一个javis.json文件，用来作全局配置
4. 架构：主代理+特定功能的子代理

要求：
1. 先到github上找相关开源的优秀项目做参考
2. deepagents更新很快，我给你配置了一个langchain mcp，你先看一下它最新版本的功能和语法再实现
- 以上两点要求是强制的，缺一不可

我要使用的模型写在文件 `@.env` 里了

项目目标：100%对标钢铁侠的javis——可探讨技术、可学习知识、可共创方案、可执行任务
