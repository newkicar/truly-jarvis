### 阻塞项（sok 侧，需修复后 jarvis 才能接入）

1. **`mcp` 包未声明依赖**：`pyproject.toml` 的 dependencies 和 server extras 里都没有 `mcp`。`from mcp.server.fastmcp import FastMCP` 会 ImportError
2. **MCP 路由未挂载**：`sok/server/app.py` 的 `create_app()` 和 `demo/run_server.py` 都没有调用 `mount_mcp()` 或 `mount_employee_routes()`。服务启动后 `/mcp` 端点不可用
3. **API Key 映射未配置**：`auth.py` 的 `API_KEY_TO_PERSON` 需要管理员配置实际的 key→person 映射

### jarvis 侧需要做的事

1. `jarvis.json` 添加 sok MCP server 配置（`type: "remote"`, `url: "http://<sok-ip>:8000/mcp"`）
2. `.env` 添加 `SOK_API_KEY` 和 `SOK_SERVER_URL`
3. `schedules/pull-sok-tasks.json` 定时任务（每 30 秒轮询待办）

## 5. EmployeeTask 状态机

```
pending ──claim()──> claimed ──complete()──> done
   │                    │
   │                    ├──fail()──> failed
   │                    │
   │                    └──retry()──> pending
   │
   └──escalate()──> escalated
```

超时：pending 30 分钟 → escalated；claimed 120 分钟 → 回退 pending。
